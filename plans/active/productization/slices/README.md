# Productization slices

Slices are ordered by dependency. Each completed slice must produce a demonstrable
product path, not only an internal layer.

- [ ] [04 — Publish an attributed change](./04-publish-attributed-change.md)

- [ ] [06 — Activate an approved capability](./06-activate-approved-capability.md)

- [ ] [08 — Operate and audit the product](./08-operate-and-audit-the-product.md)

## Completion rule

A slice is complete only when its demonstration can be performed from the supported
product surface, its security properties have automated checks where practical, and
its operator-visible failure states identify corrective action without exposing a
credential.
