## Archived plans — do not load unless asked

Everything under this directory describes **already delivered** work. The code,
its tests, and the published API schema are the authority on how that work
behaves.

- Do not read these files to gain context about the current system. They record
  what was decided at the time, including options that were rejected and details
  that have since moved.
- Read a file here only when the user asks for the history or the rationale of a
  specific delivered feature, by name.
- Do not edit these files to reflect new behaviour. Superseded decisions belong in
  the active plan that supersedes them.
